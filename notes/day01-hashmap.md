# 第 1 天 · 10-26 · HashMap

## 要点

| 要点 | 说明 |
| --- | --- |
| 结构（JDK8） | 数组 + 链表 + 红黑树，默认容量 16，负载因子 0.75 |
| hash 扰动 | `h ^ (h >>> 16)`，让高 16 位参与下标计算，减少碰撞 |
| 下标 | `(n - 1) & hash`，所以容量必须是 2 的幂 |
| 树化条件 | 链表长度 ≥ 8 且数组长度 ≥ 64；否则先扩容；节点 ≤ 6 退化为链表 |
| 线程不安全 | 并发 put 会丢数据、size 不准；JDK7 头插法扩容可能成环 |

**put 流程**：算 hash → 表为空则 `resize` 初始化 → 槽位空直接放 → 键相同则覆盖 → 否则挂链表尾部或插入红黑树 → 判断树化 → `++size > threshold` 时扩容。

**resize 高低位拆分**：容量翻倍；按 `hash & oldCap` 是否为 0 把链表拆成两条，低位留在原下标，高位到 `原下标 + oldCap`，无需重新计算 hash，且保持顺序（尾插）。
